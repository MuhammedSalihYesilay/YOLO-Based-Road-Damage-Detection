# Proje Önerisi (danışmana verilen)

**Proje adı:** YOLO-Based Road Damage Detection

**Özet:**
This project aims to develop a deep learning-based system for detecting and classifying road damages from images and real-time video streams. The system will automatically identify different types of road damage, such as potholes, longitudinal cracks, transverse cracks, and alligator cracks, using an object detection model trained on a publicly available road damage dataset. The performance of the trained model will be evaluated using standard object detection metrics. A web-based interface will then be developed to allow users to upload images or provide real-time camera input and visualize detected road damages with bounding boxes, damage classes, and confidence scores.

**Teknolojiler:** Python, PyTorch, Ultralytics YOLO, OpenCV, Streamlit, Git

**Sürdürülebilir kalkınma amacı:** 11. Sürdürülebilir şehirler ve topluluklar
